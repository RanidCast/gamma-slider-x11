# Gamma Slider X11

### [English](https://github.com/RanidCast/gamma-slider-x11/blob/main/README.md) | Русский

Небольшая multiOS-утилита в трее для изменения цветовой температуры экрана в Linux/X11, KDE Plasma Wayland, Windows и macOS.

В X11 приложение использует небольшой встроенный RandR gamma engine. В KDE Plasma Wayland оно управляет KWin Night Light. Нажмите на значок в трее и передвиньте слайдер, чтобы изменить температуру экрана.

> Поддержка Wayland пока требует KDE Plasma/KWin. Диапазон температуры там ограничен 1000–6500K; KWin не предоставляет приложению управление гаммой/видимостью и режимами цвета, а положение всплывающего окна определяет композитор. Другие Linux-окружения используют X11/RandR. В Windows применяется отдельный GDI-бэкенд, в macOS — таблицы CoreGraphics.

## Возможности

- Значок в трее и компактное всплывающее окно со слайдером.
- Диапазон цветовой температуры 1000–10000K в X11 и 1000–6500K в KDE Plasma Wayland.
- Опциональное отображение значения прямо на значке в трее.
- Быстрое включение/выключение эффекта.
- Режим повышенной gamma/контрастности для лучшей видимости.
- Три режима расчета цвета: классический, агрессивный и математический.
- Плавный автоматический режим день/ночь.
- Автозапуск.
- Совместимость с PyQt5 и PyQt6.
- Встроенный маленький gamma engine, без зависимости от полного Redshift.

## Платформы и требования

- Python 3.
- PyQt5 или PyQt6.

### Linux

- X11-сессия с RandR или KDE Plasma Wayland с KWin Night Light и KGlobalAccel.
- В KDE Wayland работают температура, пресеты, авторежим с расписанием и глобальные клавиши KDE; gamma-видимость и режимы расчета цвета недоступны.
- Для глобальных клавиш KDE требуются PyQt5 и `python-dbus`. В Arch/CachyOS установите `python-dbus`: `sudo pacman -S python-dbus`.

На многих дистрибутивах PyQt уже установлен. Если нет, поставьте пакет из репозиториев вашей системы, например `python-pyqt5`, `python3-pyqt5` или `python3-pyqt6`.

## Windows

Распакуйте архив `gamma-slider-windows-<ver>.zip` из GitHub Releases целиком и запустите `gamma-slider.exe`. Папка `_internal` должна находиться рядом с exe-файлом. Установщик не нужен.

Запуск из исходников требует Python 3 и PyQt5 (или PyQt6).

Windows-версия поддерживает автозапуск для текущего пользователя через меню приложения. Права администратора не нужны.

Выключите Windows Night Light. HDR и часть NVIDIA-драйверов игнорируют `SetDeviceGammaRamp`, поэтому слайдер может не менять картинку.

Имя репозитория `x11` историческое. На Windows используется отдельный GDI-бэкенд гаммы.

Три режима цвета доступны в Windows, macOS и Linux/X11. В KDE Plasma Wayland температуру применяет сам KWin; режимы цвета и gamma-видимость он приложению не предоставляет.

## macOS

Скачайте `gamma-slider-macos-<ver>.dmg` из GitHub Releases (или артефакт workflow). Откройте образ и перетащите **Gamma Slider** в Applications.

Сборка с GitHub рассчитана на Apple Silicon (`arm64`). Intel Mac в этот DMG не входит.

Приложение не нотаризовано. При первом запуске: правый клик → Открыть, либо:

```bash
xattr -cr "/Applications/Gamma Slider.app"
```

Выключите Night Shift и True Tone. HDR-дисплеи могут игнорировать gamma-таблицы, тогда слайдер ничего не изменит.

Автозапуск для текущего пользователя — LaunchAgent из меню приложения. Права администратора не нужны.

Запуск из исходников требует Python 3 и PyQt5 (или PyQt6).

## Установка

```bash
git clone https://github.com/RanidCast/gamma-slider-x11.git
cd gamma-slider-x11
./install.sh --install
```

Проверить установку:

```bash
./install.sh --check
```

Запустить сразу:

```bash
python3 app.py
```

После установки Gamma Slider появится в меню приложений и добавится в автозагрузку.

## Удаление

```bash
./install.sh --uninstall
```

Команда удаляет пункт меню, автозагрузку, конфиг, логи и распакованный gamma engine из профиля пользователя. Папка с исходниками проекта не удаляется.

## Горячие клавиши и CLI

По умолчанию `Ctrl+Alt+PgUp` делает теплее (+100 K), `Ctrl+Alt+PgDown` — холоднее. Температура меняется только когда эффект включён и авторежим выключен.

В Windows, macOS, Linux/X11 и KDE Plasma Wayland настроенные сочетания работают, когда фокус у другого приложения. В KDE Wayland их регистрирует KGlobalAccel; выберите сочетания в настройках приложения или в «Параметры системы → Сочетания клавиш». Удержание клавиши повторяет изменение температуры. Сочетания активны только при включённом эффекте и выключенном Auto. Если сочетание уже занято, KDE может его отклонить.

Второй запуск передаёт команду уже работающей копии:

```bash
python3 app.py --warmer
python3 app.py --cooler
python3 app.py --toggle
python3 app.py --temp 4000
```

В Linux/X11 приложение пассивно захватывает настроенные сочетания. В KDE Plasma Wayland глобальные клавиши регистрируются через KGlobalAccel: выберите сочетания в настройках приложения, KDE сохранит их вместе с остальными глобальными клавишами пользователя. Они активны, только когда эффект включён и Auto выключен; занятое сочетание может быть отклонено. В других Wayland-окружениях назначайте CLI-команды в системных настройках клавиатуры. Страница настроек показывает точный argv этой установки, а не имя .desktop-файла. Средний клик переключает эффект, только если Qt получает `MiddleClick`; в GNOME AppIndicator это событие часто не доходит, поэтому средний клик остаётся обходом для меню, как описано ниже.

Колесо мыши по значку в трее и отдельная температура на каждый монитор в этой версии нет. Кнопки 3000 / 4000 / 6500 выключают авторежим и ставят эту температуру. Время расписания меняется в настройках.

## Известные проблемы в окружении GNOME

Если вы используете графическую оболочку GNOME, пожалуйста, учтите специфику работы её системного трея:

1. **Отсутствие значка:** В чистом GNOME поддержка системного трея полностью вырезана разработчиками. Чтобы значок программы появился на панели, вам необходимо вручную установить и включить расширение **AppIndicator and KStatusNotifierItem Support**.
2. **Глюк с кликами мыши:** Из-за особенностей передачи событий мыши расширением GNOME в приложения на PyQt, одиночный клик (как левой, так и правой кнопкой мыши) по значку может ошибочно активировать контекстное меню и сразу нажать кнопку «Выход».
   - **Как обойти:** Используйте **двойной клик ЛКМ** для корректного открытия окна программы. Чтобы вызвать меню настроек без риска закрыть приложение, нажимайте на значок **колёсиком мыши (средней кнопкой)**.

В KDE Plasma Wayland Gamma Slider использует KWin Night Light. Другие Wayland-окружения пока не поддерживаются; для них используйте X11-сессию.

## Заметки

Встроенный engine распаковывается при первом запуске сюда:

```text
~/.local/share/gamma-slider/gamma-engine
```

Конфиг хранится здесь:

```text
~/.config/gamma-slider/gamma_slider.conf
```

Логи хранятся здесь:

```text
~/.local/share/gamma-slider/gamma_slider.log
```

На macOS конфиг: `~/Library/Application Support/gamma-slider/gamma_slider.conf`, логи: `~/Library/Logs/gamma-slider/gamma_slider.log`.

Приложение проверялось в KDE/Plasma, Cinnamon и Xfce под X11.
